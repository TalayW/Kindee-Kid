# กินดี Kids

เว็บแอปต้นแบบสำหรับโครงงานระดับประถม **I-New Gen Junior 2027** ช่วยเด็กบันทึกมื้ออาหารจากรูป เลือกจำนวนอาหารแต่ละกลุ่ม ดูความสมดุลแบบ 2:1:1 ติดตามน้ำดื่ม และดูกราฟย้อนหลัง 7 วัน

## เปิดใช้งานแบบง่ายที่สุด

เปิดไฟล์ `kindee-standalone.html` ด้วย Chrome หรือ Edge ได้ทันที ไฟล์นี้รวม HTML, CSS และ JavaScript ไว้ในไฟล์เดียว

## เปิดโค้ดแบบแยกไฟล์

1. เปิดโฟลเดอร์นี้ใน Codex หรือ Visual Studio Code
2. เปิด Terminal
3. รันคำสั่ง

```bash
python -m http.server 8000
```

4. เปิดเบราว์เซอร์ที่ `http://localhost:8000`

การรันผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ จะทำให้ติดตั้งเป็น PWA และใช้งานออฟไลน์ได้สมบูรณ์กว่าการดับเบิลคลิก `index.html`

## สิ่งที่แอปทำได้

- บันทึกมื้อเช้า กลางวัน เย็น และอาหารว่าง
- ถ่ายหรืออัปโหลดรูปอาหาร โดยย่อรูปก่อนเก็บ
- เลือกอาหาร 5 กลุ่มเป็นหน่วย “ส่วน”
- มีเมนูตัวอย่างอาหารไทยให้กดเติมค่าเริ่มต้น
- คำนวณคะแนนสมดุล 0–100 พร้อมคำแนะนำเชิงบวก
- บันทึกจำนวนแก้วน้ำ
- ดูประวัติและกราฟย้อนหลัง 7 วัน
- ส่งออก CSV สำหรับวิเคราะห์ผลทดลอง
- สำรอง/นำเข้าข้อมูล JSON
- เก็บข้อมูลไว้ในอุปกรณ์ด้วย `localStorage`
- ทำงานออฟไลน์เมื่อเปิดผ่านเว็บเซิร์ฟเวอร์และติดตั้ง PWA

## โครงสร้างไฟล์

```text
kindee-app/
├── index.html            โครงสร้างหน้าจอ
├── styles.css            รูปแบบและหน้าจอมือถือ
├── app.js                การบันทึก คำนวณ และแสดงผล
├── icon.svg              โลโก้แอป
├── manifest.webmanifest  ข้อมูลสำหรับติดตั้ง PWA
├── sw.js                 เก็บไฟล์เพื่อทำงานออฟไลน์
├── CODEX_PROMPT.md       ข้อความสั่ง Codex สำหรับพัฒนาต่อ
└── build_standalone.py   รวมโค้ดเป็นไฟล์ HTML เดียว
```

## สูตรคะแนนต้นแบบ

คะแนนถูกออกแบบเพื่อใช้ **เรียนรู้พฤติกรรม** ไม่ใช่ประเมินรูปร่างหรือใช้วินิจฉัยสุขภาพ

- ความสมดุลของมื้อหลัก 3 มื้อ: 54 คะแนน
- ผลไม้: 10 คะแนน
- นม: 8 คะแนน
- น้ำเปล่า: 12 คะแนน
- การบันทึกมื้อหลักสม่ำเสมอ: 8 คะแนน
- การเลือกเครื่องดื่ม/อาหารว่าง: 8 คะแนน

สามารถปรับสูตรในฟังก์ชัน `calculateScore()` ภายใน `app.js`

## ขอบเขตที่ควรบอกกรรมการอย่างตรงไปตรงมา

ต้นแบบรุ่นนี้ **ไม่ได้ใช้ AI จำแนกอาหารอัตโนมัติ** เด็กหรือผู้ปกครองเป็นผู้ยืนยันหมู่อาหารจากภาพ เพื่อให้ผลโปร่งใสและตรวจสอบได้ การพัฒนาระยะต่อไปสามารถเพิ่มโมเดลจำแนกภาพและฐานข้อมูลคุณค่าทางโภชนาการที่ผ่านการตรวจสอบโดยผู้เชี่ยวชาญ

แอปไม่คำนวณน้ำหนักเป้าหมาย ไม่สั่งให้อดอาหาร และไม่ใช้แทนคำแนะนำของแพทย์หรือนักกำหนดอาหาร

## สร้างไฟล์ Standalone ใหม่หลังแก้โค้ด

```bash
python build_standalone.py
```

ระบบจะสร้าง `kindee-standalone.html` ไว้หนึ่งระดับเหนือโฟลเดอร์โปรเจกต์

## ความเป็นส่วนตัว

ข้อมูลและรูปอยู่ในเบราว์เซอร์ของอุปกรณ์เท่านั้น ไม่มี backend และไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ ผู้ใช้ควรหลีกเลี่ยงรูปที่เห็นใบหน้า ชื่อเต็ม ที่อยู่ หรือข้อมูลส่วนตัวอื่น
