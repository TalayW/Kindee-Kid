# กินดี Kids AI — เวอร์ชันพร้อมเชื่อมระบบวิเคราะห์ภาพ

เว็บแอปต้นแบบสำหรับโครงงาน **I-New Gen Junior Award 2027** ของเด็กชายปุญญธร วรัญญูรัตนะ ชั้น ป.4 โรงเรียนสฤษดิเดช โดยมีนางสาวนงลักษณ์ เทพสิทธาวิวัฒน์ ครู คศ.3 เป็นอาจารย์ที่ปรึกษา

แอปช่วยเด็กเรียนรู้จากอาหารที่กินจริงผ่านขั้นตอน:

1. ถ่ายหรือเลือกรูปอาหาร
2. กดให้ AI ช่วยระบุอาหารที่มองเห็น
3. AI ประเมินอาหาร 5 กลุ่มและจำนวน “ส่วน” เบื้องต้น
4. ระบบคำนวณช่วงพลังงาน คาร์โบไฮเดรต โปรตีน ไขมัน และใยอาหารจากหน่วยส่วนอาหาร
5. เด็กหรือผู้ปกครองตรวจและแก้ผลก่อนบันทึก
6. แอปสรุปความสมดุลแบบ 2:1:1 และแสดงประวัติย้อนหลัง 7 วัน

## สิ่งสำคัญที่สุด

AI **ไม่สามารถรู้สารอาหารที่แน่นอนจากรูปเดียว** เพราะภาพไม่บอกน้ำหนักอาหาร สูตรอาหาร ปริมาณน้ำมัน น้ำตาล ซอส หรือส่วนที่ถูกบัง ระบบจึงแสดงเป็น “ช่วงประมาณเพื่อการเรียนรู้” และให้ผู้ใช้ยืนยันทุกครั้ง

คำอธิบายที่เหมาะกับการประกวด:

> AI ช่วยจำแนกอาหารที่มองเห็นและประเมินอาหาร 5 กลุ่มเบื้องต้น จากนั้นผู้ใช้ตรวจสอบและแก้ไขผลก่อนบันทึก ระบบจึงคำนวณช่วงสารอาหารและความสมดุลของมื้ออาหารเพื่อการเรียนรู้

ไม่ควรใช้คำว่า “ตรวจสารอาหารได้แม่นยำจากภาพ” หรือ “วินิจฉัยภาวะโภชนาการ”

## สถาปัตยกรรม

- `index.html`, `styles.css`, `app.js` — ระบบบันทึกและคะแนนเดิม
- `ai.js` — หน้าจอ AI การตรวจผล และคำนวณช่วงสารอาหารในเบราว์เซอร์
- `config.js` — ตั้งค่าที่อยู่ AI backend โดยไม่เก็บคีย์ลับ
- `api/analyze-food.js` — Vercel Serverless Function ส่งภาพจานอาหารไปยัง OpenAI Responses API
- `OPENAI_API_KEY` — เก็บเป็น Environment Variable บน Vercel เท่านั้น
- ข้อมูลโปรไฟล์และประวัติอาหารอยู่ใน `localStorage` ของอุปกรณ์
- ส่งไป AI เฉพาะรูปที่ผู้ใช้กดวิเคราะห์ ไม่ส่งชื่อเล่น ระดับชั้น หรือชื่อโรงเรียน

## เปิดแบบไม่ใช้ AI

รันเว็บเซิร์ฟเวอร์เล็ก ๆ:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ฟังก์ชันบันทึกแบบเลือกหมู่อาหารเองยังใช้งานได้ แต่ปุ่ม AI จะยังไม่ทำงานจนกว่าจะมี backend

## เปิดพร้อม AI แบบง่ายที่สุด

นำ Repository ทั้งชุดไป Deploy บน Vercel แล้วตั้งค่า Environment Variable:

```text
OPENAI_API_KEY=คีย์จริงที่ใส่ในหน้า Vercel เท่านั้น
OPENAI_MODEL=gpt-5.6-terra
OPENAI_IMAGE_DETAIL=auto
ALLOWED_ORIGINS=https://khunweew.github.io
```

ดูขั้นตอนเต็มใน `DEPLOY_VERCEL_TH.md`

## ใช้หน้าเดิมบน GitHub Pages ต่อ

เมื่อได้ลิงก์ Vercel แล้ว แก้ `config.js`:

```js
window.KINDEE_CONFIG = Object.freeze({
  aiEndpoint: "https://ชื่อโปรเจกต์.vercel.app/api/analyze-food",
  aiRequestTimeoutMs: 45000
});
```

จากนั้น commit และ push ไป GitHub หน้า `https://khunweew.github.io/kindee-kids/` จะเรียก backend บน Vercel โดยคีย์ยังไม่ปรากฏใน GitHub

## ความปลอดภัยสำหรับเด็ก

- ใช้บัญชีและ API key ของผู้ปกครอง ครู หรือผู้รับผิดชอบโครงการ ไม่ให้เด็กถือคีย์เอง
- ห้ามถ่ายภาพที่เห็นใบหน้า ป้ายชื่อ ชุดนักเรียน ที่อยู่ หรือข้อมูลส่วนตัว
- ภายในโค้ดตั้ง `store: false` สำหรับคำขอวิเคราะห์
- แอปไม่คำนวณน้ำหนักเป้าหมาย ไม่ชวนอดอาหาร และไม่ตำหนิรูปร่าง
- ไม่ใช้แทนคำแนะนำจากแพทย์หรือนักกำหนดอาหาร

## ทดสอบโค้ด

```bash
npm test
npm run check
```

แบบทดสอบไม่เรียก API จริง แต่จำลองผลเพื่อเช็กการรับส่งข้อมูลและการปรับจำนวนส่วน

## ทดสอบความแม่นยำก่อนเขียนลงแบบฟอร์ม

ใช้ไฟล์:

- `AI_VALIDATION_PLAN_TH.md`
- `AI_VALIDATION_TEMPLATE.csv`
- `NRIIS_AI_UPDATE_TEXT_TH.md` สำหรับปรับข้อความแบบฟอร์มหลังเพิ่ม AI

แนะนำทดสอบอย่างน้อย 30 ภาพ และรายงานผลจริง เช่น ความถูกต้องของการพบอาหาร 5 กลุ่ม ค่าเฉลี่ยความคลาดเคลื่อนของจำนวนส่วน อัตราที่ผู้ใช้ต้องแก้ผล และเวลาเฉลี่ยต่อภาพ
